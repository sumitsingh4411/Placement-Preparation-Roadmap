## ✍️ Writing the bullets

**Formula:** `[Action verb] + [what you did] + [how/with what tech] + [quantified result]`

<div align="center">

| ❌ Weak | ✅ Strong |
|---|---|
| Worked on the frontend | Built 12 reusable React components with TypeScript, reducing new-page development time by ~40% |
| Made the app faster | Reduced initial page load from 4.2s to 1.1s using code splitting and image lazy loading |
| Used a database | Designed a normalised PostgreSQL schema across 14 tables with foreign key constraints and composite indexes |
| Added login | Implemented JWT authentication with refresh token rotation and bcrypt hashing, supporting 3 user roles |
| Handled lots of data | Built server-side pagination and filtering over 50,000+ records with sub-200ms response times |
| Tested the app | Wrote 45 unit and integration tests with Jest, raising coverage from 32% to 78% |
| Deployed it | Containerised with Docker and deployed to AWS EC2 via a GitHub Actions CI/CD pipeline |

</div>

### Action verbs that work

`Built` · `Implemented` · `Designed` · `Developed` · `Reduced` · `Optimised` · `Automated` · `Architected` · `Integrated` · `Migrated` · `Refactored` · `Deployed` · `Scaled` · `Debugged` · `Led`

**Never start with:** "Responsible for", "Worked on", "Helped with", "Was involved in"

### Where to find your numbers

- **Performance:** Lighthouse scores, Postman response times, before/after query timings
- **Scale:** number of API endpoints, database tables, records processed, concurrent users
- **Quality:** test count, coverage percentage, bugs fixed
- **Usage:** registered users, Play Store downloads, GitHub stars, page views
- **Effort:** commits, lines processed, features shipped

**Never invent numbers.** You'll be asked "how did you measure that?" — have a real answer.

## ✅ Pre-submit checklist

**Format**
- [ ] Exactly **one page**
- [ ] Exported as **PDF**, named `Firstname_Lastname_Resume.pdf`
- [ ] **Single column** — no sidebars
- [ ] No tables, text boxes, images, icons, charts, or skill rating bars
- [ ] Standard font, 10–11pt, consistent throughout
- [ ] Consistent date format (`Jun 2025` everywhere)
- [ ] Margins 0.5"–1", nothing cramped

**Content**
- [ ] Professional email (`firstname.lastname@gmail.com`)
- [ ] LinkedIn, GitHub and portfolio links are **hyperlinked** and correct
- [ ] **Every project has a live link** where possible
- [ ] Every bullet starts with an action verb
- [ ] At least half the bullets contain a **number**
- [ ] Skills list contains only things you can be interviewed on
- [ ] No objective/summary section
- [ ] No photo, DOB, father's name, marital status, address, or declaration
- [ ] CGPA included only if 7.0+

**Quality**
- [ ] **Zero typos** — run Grammarly, then have someone else read it
- [ ] Consistent tense — past for finished work, present for ongoing
- [ ] No first person ("I built" → "Built")
- [ ] Every link actually opens and works

**ATS check**
- [ ] Pasted the PDF into a plain text editor — content is in the right order and nothing is missing
- [ ] Keywords from the target job description appear naturally
- [ ] Checked on [Resume Worded](https://resumeworded.com/) or [Jobscan](https://www.jobscan.co/)

**Final**
- [ ] Reviewed by someone else *(r/EngineeringResumes, a senior, or an engineer on LinkedIn)*
- [ ] Tailored version saved per target company
