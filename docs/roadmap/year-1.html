🌱 Year 1 — Build the Base

Goal: by May, you can write real code in one language and you've solved 150 problems.#

🏠 Home • 🗺️ All roadmaps • Year 2 →

Why year 1 is your biggest advantage#

You have four years of runway and almost no pressure. A tier-1 student who started in class 11 has a 2-year head start. You can erase most of it this year, because you have more free time now than you will ever have again.

Most tier-3 students waste this year completely — "abhi to time hai." Then they panic in the 3rd year. If you do even the minimum here, you'll be ahead of 90% of your batch by year 2.

Important

This year is not about getting a job. It's about becoming someone who can code. Do not chase projects, frameworks or internships yet. Build the base.

The only 4 things that matter this year#

#GoalWhyTime
1️⃣One programming language, properlyEverything else is built on this3–4 months
2️⃣Basic DSA (arrays → recursion)Starting now = 3 years of compoundingOngoing
3️⃣Git, GitHub, Linux basicsAssumed knowledge everywhere1 month
4️⃣CGPA above 7.5Easiest marks of your degree are in year 1Ongoing

Semester 1 (Aug – Dec)#

Month 1–2: Pick a language and stop looking around#

  • Choose one: C++, Java, or Python. Write it down. Don't change it for 12 months.
  • Install VS Code + your language's compiler/runtime
  • Learn: variables, data types, operators, if/else, loops
  • Learn: functions, parameters, return values, scope
  • Learn: arrays / lists, strings, and their built-in methods
  • Write 50+ tiny programs by hand (patterns, prime numbers, reverse a string, factorial, Fibonacci, palindrome, GCD, Armstrong numbers)
🤔 Which language should I pick?
LanguagePick it ifWatch out
C++You want max speed in contests + your college teaches C/C++Harder syntax, manual memory concepts, but STL is excellent for DSA
JavaYou want service-company + enterprise + Android optionsVerbose, but the most common language in Indian mass-hiring
PythonYou want the gentlest start, or you're leaning Data/AI/MLSlower in competitive programming; some companies restrict it in OAs

Genuinely stuck? Pick C++ if you want to be strongest at DSA. Pick Java if you want the safest job-market bet in India. Both are correct. The wrong answer is switching in month 3.

Note: the language you use for DSA does not have to be the language you use at work. Learning a second language later takes 2 weeks, not 2 years.

Month 3–4: Core programming concepts#

  • OOP — classes, objects, the 4 pillars (encapsulation, abstraction, inheritance, polymorphism)
  • Constructors, static, access modifiers
  • Exception / error handling
  • File input and output
  • Basic collections — vectors/ArrayList, hashmaps/dictionaries, sets
  • Time and space complexity — what Big-O actually means

Build these small programs (no tutorials, from scratch):

  • Calculator (CLI)
  • Student marks manager (add/view/delete, saves to a file)
  • Number guessing game
  • To-do list in the terminal
  • Bank account simulator using classes

Month 5: Git, GitHub and Linux#

  • git init, add, commit, push, pull, clone, status, log
  • Branching and merging basics
  • Create your GitHub profile — professional username
  • Push everything you wrote above (yes, even the ugly code)
  • Write a README for at least one repo
  • Linux basics: cd, ls, mkdir, rm, cp, mv, cat, grep, chmod, pipes

📖 Full guide: core/git-and-linux.md

Tip

Push code every single day, even 5 lines. Recruiters and interviewers open your GitHub. A 2-year commit history with real projects is the closest thing a tier-3 student has to a brand name.

Semester 2 (Jan – May)#

Month 6–8: DSA foundations#

Start easy. The goal is building a daily habit, not speed.

  • Arrays — traversal, two pointers, prefix sum, sliding window (basic)
  • Strings — reversal, palindromes, frequency counting, anagram problems
  • Searching — linear search, binary search (and its variants)
  • Sorting — bubble, selection, insertion (understand), merge, quick (understand deeply)
  • Recursion — base case, recursive case, call stack, tracing a recursion tree
  • Basic maths — primes, sieve, GCD/LCM, modular arithmetic, digit manipulation
  • Hashing — hashmap and hashset problem patterns

Target: 100–150 problems total (LeetCode Easy + a few Medium). ~1 problem a day is enough.

📖 Full plan: core/dsa.md

😩 "I can't solve anything, every problem feels impossible"

That is exactly what it feels like for everyone at the start. Here's the rule:

  1. Try genuinely for 25 minutes. Not 5. Not 3 hours.
  2. Still stuck? Read the editorial. This is not cheating — it's how you learn patterns.
  3. Close everything and rewrite the solution from memory.
  4. Add the problem to a "revisit" list. Redo it in 7 days without looking.

If you can't solve it the second time, you didn't learn it — you just read it. That's the whole skill.

Nobody derives these patterns from first principles. You learn ~30 patterns, then problems start looking familiar. That takes about 200 problems. Just get there.

Month 9–10: Explore, then commit#

Now that you can code, sample the tracks — one week each — and pick one for year 2.

  • Web basics — HTML, CSS, and enough JavaScript to make a page interactive
  • Build one static personal portfolio page and deploy it on GitHub Pages (this is your first real "I built a thing" moment)
  • Read all 8 track files: tracks/README.md
  • Decide your track by the end of year 1. Write it down.

Month 11–12: Consolidate#

  • Revise everything — redo 30 problems you previously solved
  • Clean up your GitHub: proper READMEs, delete junk repos
  • Create a LinkedIn profile and connect with 50 people in tech
  • Set up your year-2 plan using templates/90-day-plan.md
  • Summer break: don't stop. 1 problem/day + start your first real project

✅ You're on track if, by May...#

  • You can write a 100-line program in your language without Googling syntax
  • You've solved 100–150 problems
  • Your GitHub has 10+ repos and a visible commit streak
  • You understand OOP well enough to explain it to a friend
  • You can use Git without copy-pasting commands
  • You've deployed at least one thing to the internet
  • Your CGPA is above 7.5
  • You have chosen your track for year 2

Hit 5 or more? You are genuinely ahead of most of your batch. Move to Year 2.

⚠️ Year-1 traps#

TrapWhy it happensFix
"Abhi to 3 saal hai"Year 1 feels safeThe gap you build now compounds for 3 years
Language hoppingEvery YouTuber says a different one is bestPick one. Stay 12 months. All three get you hired.
Competitive programming rabbit holeIt looks impressiveCP ≠ interview DSA. Do interview DSA. CP only if you genuinely enjoy it.
Learning React before basic JSFrameworks look coolerYou'll hit a wall in 3 weeks. Fundamentals first.
Joining every college clubFOMOOne technical club max. Time is your only real asset.
Ignoring CGPA"Skills matter, not marks"True after the resume filter. You have to pass the filter first.
Comparing to tier-1 studentsLinkedInYou see their offers, not their head start. Compare to yourself last month.
